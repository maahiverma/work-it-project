# WORK-FIT Gym Website

## Overview

WORK-FIT is a responsive gym website designed to provide users with information about fitness programs, training plans, membership options, and contact details. The website features a modern and user-friendly interface suitable for desktop, tablet, and mobile devices.

## Features

* Responsive design for all screen sizes
* Home page with gym introduction
* Training Programs section

  * Zumba Training
  * Weight Loss Programs
  * Strength & Weight Gain Training
* Membership Plans section
* Contact Us page with inquiry form
* Interactive hover effects and modern UI design
* Easy navigation through the navbar

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries for responsiveness

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `home.html` in any modern web browser.
4. Navigate through the website using the navigation menu.

## Responsive Design

The website is fully responsive and adapts to:

* Desktop screens
* Tablets
* Mobile devices

Media queries have been used to ensure optimal viewing experience across different screen sizes.
